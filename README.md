# Real-Time-Health-Monitoring-System-8051-
Real-time Multi-Parameter Health Monitoring System using 8051 Microcontroller

This project monitors multiple health parameters using Embedded C and detects abnormal conditions.

## Parameters:
- Temperature
- Heart Rate
- SpO₂
- Activity

## Features:
- Condition-based alerts
- Multi-parameter decision logic
- LED indication system

## Conditions:
- Normal
- Fever
- Heart Issue
- Low Oxygen (Blink)
- Critical

## Tools Used:
- Keil uVision
- EdSim51

## Note:
Sensor values are simulated for demonstration purposes.
